# 提示词配方

方括号为待替换内容。提示词服务于已确定的设计方案；调用前移除无关段落，不把所有配方一次塞给模型。只填写有依据的日期、数字、价格和标识。

## 先用几行确定方案

> 目的/受众：[让谁记住什么或做什么]。  
> 层级：[主标题] → [副标题/利益点] → [时间地点/行动入口]。  
> 布局：[editorial/product/event/cover/info]；[主体位置]；[文字区域]。  
> 视觉：[配色名称与色值]，[字体方向]，[参考图中可借鉴的结构]。  
> 制作：[直接生成完整图 / 无字主视觉 + HTML/SVG 叠字]；缺项按[合理假设]处理。

用户已要求出图时，简短说明后继续调用，不默认等待确认。

## A. 短文案完整海报

```text
设计一张[用途]海报，面向[受众]，核心信息是[信息]。
采用[版式]：[主标题位置]，[主体位置]，[底部信息位置]。
仅出现以下准确文案，不添加其他字：
主标题：“[短标题]”
副标题：“[副标题]”
辅助信息：“[真实信息，可省略]”
主标题最醒目，副标题明显次一级，辅助信息清楚但不过度抢眼。
背景[色值]，主色[色值]，强调色[色值]；画面面积约[比例]。
主体为[原创主体与具体材质/光线]。
四周保留约[7%]安全边距，文字背后低细节且明暗稳定。
使用简洁[无衬线/衬线]排版，保持同一对齐线与稳定行距。
不添加虚构品牌、乱码、水印、额外标签或装饰文字。
```

文字由模型生成仍可能出错；需要精确交付时检查实际输出，或改为配方 B。不要宣称生成式文字一定准确。

## B. 长文案用无文字主视觉

```text
生成用于[用途]的原创主视觉，画布比例[比例]。
主体[描述]置于画面[位置]，占约[比例]，完整保留[关键细节]。
预留文字区域：左侧[40%]为连续平整的[背景色]，用于后期放标题与正文；
顶部[12%]和底部[15%]保留低细节空间，用于栏目与信息。
这些区域不要出现主体、边缘高光、复杂纹理、强烈阴影或高反差图案。
其余背景使用[简洁环境/原创几何图形]，配色为[色值及角色]。
画面不含任何文字、数字、字母、标识、水印或二维码。
```

随后以 [HTML 模板](../templates/poster.html) 或可编辑 SVG 叠字：填写真实文案、设置字体回退、调整分行，核对溢出及安全区。根据版式替换左侧留白，例如封面可用顶部 35%，活动可用上下信息区。生成图不保证精确百分比，叠字前应检查实际空区，必要时调整布局。

HTML 可由用户在浏览器中打开后打印或截图导出；没有可用浏览器工具时交付可编辑文件，不声称已生成 PNG。只有浏览器工具实际可用时才执行自动导出并检查结果。

## C. 已有图局部编辑

```text
基于输入图进行编辑，用于[用途]。
必须保留：[产品形状/人物特征/主要构图/用户要求保留的标识]。
只修改：[背景/主体位置/色调/指定局部]。
把主体调整到[位置]；[区域]留作后期文字区，改为连续平整的[色值]背景。
主体边缘自然，光线与阴影一致，关键细节清晰。
参考图仅借鉴[网格/层级/留白/色彩关系]，重新组织原创构图，不照搬独特图形、插画或标识。
不额外生成文字、水印、品牌或装饰标签。
```

工具输入使用实际存在的本地图片；如使用蒙版，先确认尺寸与输入图匹配。严格保真的产品、标识与包装文字应检查实际输出，必要时使用原图叠加。

## D. 信息卡片背景

```text
生成适合知识信息卡的原创简洁背景，比例[比例]。
底色[色值]，仅在[角落/侧边]放少量[原创几何形]，强调色[色值]。
中央[约80%]区域平整、明暗稳定，供后期放多段正文与数字。
装饰不跨越文本区，不形成类似文字、图表、数字或二维码的图案。
不含任何文字、字母、标识和水印。
```

信息内容与图表由 HTML/SVG 排版；图表必须来自真实数据，复杂内容拆为多页。

## 参数示例

普通模型按比例默认尺寸，不必填写 `size`：

```json
{
  "model": "gpt-image-2.5",
  "aspect_ratio": "3:4",
  "prompt": "替换为已完成的具体提示词"
}
```

已有图编辑的示例，图片路径须替换为真实本地文件：

```json
{
  "model": "gpt-image-2.5",
  "image_paths": ["/实际工作区/输入图.png"],
  "aspect_ratio": "3:4",
  "prompt": "替换为具体编辑指令"
}
```

用户显式指定 `size` 时优先使用该尺寸，不再用比例覆盖。显式 2K/4K 或长边超过 2048 可能路由到 Sunburst；不要暗中升级，任何 Sunburst 调用都须本次交互明确批准。示例只是参数结构，不代表工具已调用或图片已生成。

## 交付表述

用一句话说明产物和布局，再列必要假设或未验证项。成功生成后提供工具返回的实际文件；HTML/SVG 说明如何打开与导出。不要把未执行的出图、未完成的检查或不存在的 PNG 写成完成事项。
